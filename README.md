## 🎯 Analysis of Employee Behavior

### Computer Vision · Video Analytics · End-to-End AI

An end-to-end Computer Vision system designed to analyze human activity and productivity from video data.

### 🔥 System Architecture

```text
                         VIDEO INPUT
                              │
                              ▼
                           YOLO11
                              │
                              ▼
                     PERSON DETECTION
                              │
                              ▼
                     BoT-SORT + Re-ID
                              │
                              ▼
                    STABLE PERSON ID
                              │
                              ▼
                     PERSON SEQUENCES
                              │
                ┌─────────────┼─────────────┐
                ▼             ▼             ▼
             OBJECT         ACTION         POSE
           DETECTION      SlowFast      MediaPipe
                │             │             │
                └─────────────┼─────────────┘
                              ▼
                     OBJECT ASSOCIATION
                              │
                              ▼
                           TIMELINE
                              │
                              ▼
                      MODEL FUSION
                              │
                              ▼
                        RULE ENGINE
                              │
                              ▼
                    PRODUCTIVITY ANALYSIS
```

### Core Technologies

`Python` `YOLO11` `BoT-SORT` `Re-ID` `SlowFast` `MediaPipe` `OpenCV` `PyTorch`
